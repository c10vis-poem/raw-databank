## The general rule that applies to everything in this salvage dump

Nothing in this corpus is canon unless the operator adopted it. When citing
anything here, say which it is:

| Label | Means |
|---|---|
| **adopted** | The operator said it directly. Rare. |
| **candidate** | In the pile, not yet selected. Most things. |
| **superseded** | Overtaken — say by what. |
| **transcript** | An AI chat log. Architecture dictated *by the operator* inside one is adoptable; the AI's implementation claims never are. |

`FEATURE-SPEC.md` says "Canonical." Both were mid-thought. Reading "defined" on a
folder and believing it is how a metaphor became a state machine and a protocol
